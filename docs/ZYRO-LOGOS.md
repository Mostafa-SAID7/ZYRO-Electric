## Imagery Style Guide

### Product Photography

```
Background: White (#FFFFFF) or Light Gray (#F3F4F6)
Lighting: Even, professional
Props: Minimal, contextual
Orientation: 45° angle preferred
Format: High-resolution (2400x2400px+)
```

### Lifestyle Photography

```
Style: Modern, aspirational
Tone: Professional yet approachable
Subjects: Real people, diverse representation
Settings: Organized, clean workspaces
Color Palette: Complements ZYRO colors
```

### Graphic Design

```
Style: Minimalist, geometric
Colors: Primary palette + white space
Fonts: Inter family
Icons: Lucide/Heroicons
Consistency: Maintain style across all assets
```
