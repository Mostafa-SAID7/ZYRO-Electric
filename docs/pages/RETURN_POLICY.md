# Return Policy

**Effective Date:** August 11, 2026  
**Last Updated:** August 11, 2026

## 1. Return Eligibility

### 1.1 Eligible Products

Most items purchased from ZYRO can be returned within **30 days** of delivery if they meet these conditions:

- **Unused & Unopened**: Product must be in original, unused condition
- **Original Packaging**: Item must be in original packaging with all accessories
- **No Damage**: No signs of wear, scratches, or damage (normal shipping protection only)
- **With Receipt**: Original purchase receipt or order confirmation number
- **Refundable Category**: Most items are returnable (see exceptions below)

### 1.2 Non-Returnable Items

The following items cannot be returned:

- **Clearance Items**: Marked as "clearance" or "final sale"
- **Custom/Made-to-Order**: Personalized or custom-built products
- **Digital Products**: Software, licenses, or digital downloads
- **Opened Electrical Items**: For safety/hygiene reasons (some electronics may be returnable if unopened)
- **Damaged by Misuse**: Damage from user error or mishandling
- **Items Outside Return Window**: Returns after 30 days
- **Original Receipt Missing**: Cannot verify purchase

## 2. Return Process

### 2.1 Step-by-Step Instructions

**Step 1: Initiate Return**
1. Log into your ZYRO account
2. Go to "Order History"
3. Find the order to return
4. Click "Return Item"
5. Select reason for return
6. Submit return request

**Step 2: Get Return Authorization**
- You'll receive email confirmation with RMA# (Return Merchandise Authorization)
- Print the return shipping label
- Use this label for return shipment

**Step 3: Ship the Item**
1. Pack item securely in original packaging
2. Affix the return shipping label
3. Ship via carrier (UPS, FedEx, USPS)
4. Keep tracking number for reference
5. Item typically arrives in 5-7 business days

**Step 4: Item Inspection**
- We inspect returned item upon receipt
- Verify condition matches return request
- Check that item is unopened/unused
- Process approved or denied status

**Step 5: Refund Processing**
- Approved: Refund processed within 5-7 business days
- Denied: Item shipped back to you at our cost
- Refund appears in original payment method

### 2.2 Return Methods

**Online Portal** (Recommended)
- Fastest and most convenient
- Get return label immediately
- Track refund status in real-time

**Email**
- Email: returns@zyro-electric.com
- Subject: "Return Request - [Order Number]"
- Include: Order number, reason, photos (if applicable)

**Phone**
- Call: 1-800-ZYRO-HELP
- Hours: Monday-Friday, 9 AM - 5 PM EST
- Agent will guide you through process

## 5. Refunds

### 5.1 Refund Amounts

| Scenario | Refund |
|----------|--------|
| Unopened/Unused Item | Full refund (100%) |
| Opened but Unused* | Full or partial refund (depends on category) |
| Used Item | No refund |
| Clearance Item | Non-returnable |
| Original Shipping | Included in refund (if we covered) |
| Your Return Shipping | Deducted (if you paid) |

*Electronics and beauty items may be non-returnable if opened for safety/hygiene

### 5.2 Restocking Fee

A restocking fee may apply:
- **Standard Items**: No fee
- **Electronics**: 15% restocking fee (if applicable)
- **Clearance**: No returns accepted
- **Customized Items**: No returns accepted

### 5.3 Refund Processing Time

| Step | Timeline |
|------|----------|
| Item Received | 1-2 days |
| Inspection | 2-3 days |
| Approval/Denial | 1 day |
| Refund Processed | 5-7 business days |
| Appears in Account | 3-5 business days after processing |

**Total: 10-21 business days from delivery to refund appearance**

### 5.4 Refund Methods

Refunds are issued to:
- **Original Payment Method**: Credit card, debit card, PayPal
- **Store Credit**: 110% as store credit (optional upgrade)
- **Account Balance**: For ZYRO wallet purchases

## 6. Exchanges

### 6.1 How to Exchange

If you need a different size, color, or model:

1. Initiate return process (see Step 1-2 above)
2. In return request, select "Exchange" instead of "Refund"
3. Select the replacement item and options
4. We ship new item immediately
5. Once we receive return, exchange is complete

### 6.2 Exchange Shipping

- **Free Outbound**: We cover shipping of new item to you
- **Return Shipping**: See "Shipping Costs" section
- **Processing Time**: 7-14 business days total

### 6.3 Price Differences

| Scenario | Your Cost |
|----------|-----------|
| Exchanging to Same Price Item | Free |
| Exchanging to Higher Price Item | Pay difference + shipping |
| Exchanging to Lower Price Item | Refund difference to original payment |

## 7. Special Circumstances

### 7.1 Defective or Damaged Items

**Report Within:** 48 hours of delivery

**Include:**
- Order number
- Photos of damage/defect
- Description of problem
- Photos of packaging (if damaged in transit)

**Resolution:**
- Free replacement shipped immediately
- Original item may be kept (no return needed)
- Return shipping covered if requested
- Full refund if item cannot be replaced

### 7.2 Wrong Item Received

**Report Within:** 48 hours of delivery

**Provide:**
- Order number
- Item received vs. item ordered
- Photos of wrong item
- Original invoice

**Resolution:**
- Correct item shipped immediately (free)
- Wrong item picked up at no cost
- Full refund if you prefer not to exchange
- No restocking fee

### 7.3 Item Never Arrived

**Report Within:** 30 days of order

**Provide:**
- Order number
- Tracking number
- Proof of non-delivery

**Resolution:**
- File carrier claim (if applicable)
- Replacement item shipped
- Refund issued if replacement unavailable
- No penalty
