# 🚀 ZYRO - Brand Guidelines & Assets

## Brand Overview

**ZYRO** is a modern, technology-focused e-commerce platform specializing in premium technology accessories across 10 high-growth niches. The brand represents quality, innovation, and curated tech solutions for professionals, creators, and enthusiasts.

## Logo Usage Guidelines

### Clear Space

```
Minimum clear space around logo:
  
    [ZYRO]
  ◄─┤└────┤─►
   [Clear Space = 1/2 logo height]
```

### Size Requirements

| Usage | Minimum Size | Notes |
|-------|--------------|-------|
| Web (desktop) | 64px | Favicon to hero |
| Web (mobile) | 48px | Mobile navigation |
| Print | 1 inch | Business cards, flyers |
| Social media | 512px | Profile pictures |
| Email | 200px | Header |

### Do's & Don'ts

✅ **DO**:
- Use on solid backgrounds
- Maintain aspect ratio
- Use provided color versions
- Provide adequate clear space
- Scale proportionally

❌ **DON'T**:
- Stretch or distort
- Change colors without permission
- Add effects (shadows, glows)
- Use outdated versions
- Rotate at non-standard angles

## Visual Style Guide

### Photography Style

**Product Photography**:
- Clean, minimalist backgrounds (white or light gray)
- Professional lighting
- Multiple angles
- Lifestyle context shots
- Consistent styling

**Lifestyle Photography**:
- Real people, real setups

- Inspiring, aspirational
