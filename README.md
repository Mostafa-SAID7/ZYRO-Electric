# 🛒 Market

> Modern e-commerce platform built with Angular 18 and Tailwind CSS

[![Angular](https://img.shields.io/badge/Angular-18.2-red?style=flat-square&logo=angular)](https://angular.io/)
[![Tailwind](https://img.shields.io/badge/Tailwind-3.4-38bdf8?style=flat-square&logo=tailwindcss)](https://tailwindcss.com/)
[![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)](LICENSE)

## Quick Start

```bash
npm install --legacy-peer-deps
npm start
```

Navigate to `http://localhost:4200/`

## Build

```bash
npm run build
```
