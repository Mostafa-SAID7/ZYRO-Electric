🔐 AUTHENTICATION FOR NPM PACKAGE:

For developers to install @mostafa-said7/zyro, they need:

1. Create GitHub Personal Access Token:
   - Go to GitHub Settings > Developer settings > Personal access tokens
   - Select "classic" tokens (or fine-grained)
   - Scopes needed: read:packages
   - Copy token

2. Create/Update .npmrc file:
   @mostafa-said7:registry=https://npm.pkg.github.com
   //npm.pkg.github.com/:_authToken=YOUR_TOKEN_HERE

3. Or login with npm:
   npm login --registry=https://npm.pkg.github.com
   Username: YOUR_GITHUB_USERNAME
   Password: YOUR_GITHUB_TOKEN
   Email: YOUR_EMAIL

4. Then install:
   npm install @mostafa-said7/zyro
